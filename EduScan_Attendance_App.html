Google Sheets Integration

Connect this app directly to your Google Sheet using a free Google Apps Script Web App. Every scanned QR code will automatically append a new row to your spreadsheet.

1. Copy this Apps Script Code 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Add header row if sheet is empty
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Timestamp", "Student ID", "Student Name", "Class", "Course", "Status"]);
  }
  
  sheet.appendRow([
    data.timestamp,
    data.studentId,
    data.studentName,
    data.studentClass,
    data.course,
    data.status
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Open your Google Sheet → click Extensions → Apps Script.
  2. Paste the code above and click Deploy → New deployment.
  3. Select type Web app, set Who has access to Anyone, and click Deploy.
  4. Paste the generated Web App URL above and click Save.
